# WhatsApp J2ME

An experimental Java ME messaging client concept for vintage phones. The project explores a classic mobile interface alongside modern messaging connectivity through a companion bridge.

## Project overview

- Chat list and conversation views
- Contact and message models with local storage
- QR-based session flow
- Message notifications and voice-call interface
- MIDP 2.0 / CLDC 1.1 project configuration

The application is experimental. Its functionality depends on a compatible companion service and backend, and it is not intended for production use.

## Project contents

- `src/` — application code
- `res/` — application images and other resources
